# Steep & Bloom

A warm, responsive tea-brand landing page built as part of my frontend learning journey. The page brings together a drink collection, a brand story, tasting notes, and a small tea journal.

## What I practiced

- Translating a visual reference into semantic, accessible HTML
- CSS Grid compositions and responsive Flexbox navigation
- Fluid typography, layered cards, gradients, and image placement
- Native HTML disclosure interactions without JavaScript
- Keyboard focus, meaningful image descriptions, and reduced-motion support

## Explore

- A tea-led hero and four-drink collection
- A fresh-tea image mosaic and ingredient story
- An editorial tasting-notes panel
- Three expandable tea-journal entries
- Clear section navigation and a responsive footer

## Run locally

Open `index.html` in your browser, or serve the project folder with any static HTTP server. No package installation or build step is required.

## Built with

HTML5 and CSS3. No JavaScript, frameworks, or component libraries.

## Project structure

```text
steep-and-bloom/
├── index.html
├── styles.css
└── images/
```

## Design notes

This is a frontend practice concept, not an operating shop. The layout and photography build on supplied visual resources, with new branding, copy, and styling. Product packaging in the source images retains its original branding. Tasting cards are illustrative editorial descriptions, not verified customer reviews. No orders, payments, email subscriptions, or personal data are collected.

The original design file is preserved locally and excluded from Git tracking. This project does not claim original authorship of the supplied photography or reference layout.
